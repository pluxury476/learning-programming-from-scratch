## break, continue, else
- `break` — выйти из цикла полностью
- `continue` — пропустить текущую итерацию, идти к следующей
- `else` в цикле — срабатывает, если цикл завершился БЕЗ break
- else в for — редко используется, но полезен при поиске


## for и while 
# Мои заметки по Python

### `for` — «для каждого элемента из набора»

Когда использовать: **знаешь, сколько раз повторять**.

```python
for i in range(1, 6):
    print(i)         # 1 2 3 4 5

### while - пока условие не верно
